What is happening?

  1. Program starts: tasks are created.
  2. Task creation: the workload is split into independent tasks.
  3. Scheduling: the OS scheduler places waiting tasks on available cores.
  4. Parallel execution: multiple cores execute different tasks at the same time.
  5. Results combine: completed tasks contribute to the final workload.
